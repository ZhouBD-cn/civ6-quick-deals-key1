# Quick Deals (Key "1" 1.01)

《文明 6》Quick Deals 快捷键增强版。首次选择资源或外交支持点数后，按键盘上方的 **1**，即可重新选中同一种物品，数量固定为 **1**，方便连续进行单个物品交易。

修改版作者：[ZhouBD-cn](https://github.com/ZhouBD-cn)。原作：wltk 的 [Quick Deals](https://steamcommunity.com/sharedfiles/filedetails/?id=2460661464)。

## 下载

[下载 1.01 安装包](downloads/QuickDeals-Key1-1.01.zip?raw=true)

## 功能

- 记住上次选择的资源或外交支持点数。
- 按数字 1 重选同一种物品，数量固定为 1。
- 支持马、铁等战略资源，出售页也提供鼠标重选按钮。
- 切换物品后更新记忆，连续按键不会累加数量。
- 每笔交易由玩家手动确认。

## 安装

1. 退出游戏，下载并解压安装包。
2. 将 `QuickDealsRepeatOne` 文件夹放入：

   ```text
   文档\My Games\Sid Meier's Civilization VI\Mods\
   ```

3. 在游戏“额外内容 → 模组”中禁用原版 Quick Deals，启用 **Quick Deals (Key "1" 1.01)**。

已有此前修改版：退出游戏后覆盖同名文件夹，重启即可。

## 使用

选择物品 → 成交 → 等待报价加载结束 → 按 **1** 重选 → 继续成交。

请使用键盘上方的数字 1；小键盘 1 不触发。报价或交易正在处理、数量编辑框打开时，请等待处理完成或关闭编辑框后再使用。外交支持点数交易需要“风云变幻”。收益以实际 AI 报价为准。

## 存档兼容

通常可以继续加载此前使用原版 Quick Deals 的存档，无需重新开局。加载前禁用原版、启用本版，不要同时启用两个版本，建议保留原存档。
